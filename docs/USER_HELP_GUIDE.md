## 1. What is Solopreneur OS?

Solopreneur OS helps you run the full journey of a solo product in one place:

| Stage | What you do here |
|--------|------------------|
| Ideas | Capture and score ideas |
| Build | Track tasks, milestones, and releases |
| Leads | Find people talking about problems you solve |
| Growth | Plan content, launches, and campaigns |
| Revenue | See subscriptions and earnings |
| Code | Link GitHub and watch builds |

You work around **projects**. An idea or lead can be **promoted** into a project, which then shows up in Build Tracker, Growth Engine, and related areas.

## 2. Getting started & how to access

### Sign in

1. Go to the Solopreneur OS home page.
2. Click **Sign in** or **Get started**.
3. Complete sign-in in the secure login window (email or the options your account provider shows).
4. Click **Open Dashboard** or **Go to Command Center**.

You must be signed in to use anything under the dashboard. Privacy and Terms pages are available without signing in (links in the footer).

### Where everything lives

After sign-in, use the **left sidebar**. Each item opens a different area of the product:

| Menu item | What it’s for |
|-----------|----------------|
| **Overview** | Big-picture summary of your pipeline |
| **Brainstorm & Ideas** | Capture, score, and promote ideas |
| **Build Tracker** | Projects, tasks, milestones, builds |
| **Lead Finder** | Find and manage outreach leads |
| **Growth Engine** | Coach, content, launch playbooks, SEO |
| **Revenue & Billing** | MRR, subscriptions, transactions |
| **Repository & VCS** | Connect GitHub and monitor activity |
| **Settings** | Account, data export/delete, usage limits |
| **Help** | In-app training guide (this content) |

At the bottom of the sidebar you’ll see your account menu (profile / sign out) plus **Privacy** and **Terms**.

## 3. Finding your way around

- **One sidebar for everything** — you rarely need to leave the dashboard.
- **Projects are the hub** — after you promote an idea (or create a project), you’ll select that project in Build Tracker, Growth Engine, and Repository.
- **AI buttons** (Score, Generate, Draft reply, etc.) use your plan’s AI allowance. Check **Settings** if something fails with a limit message.
- Look for empty-state messages on each page — they usually tell you the next step (for example, “Promote an idea from Brainstorm”).

## 4. Recommended first-week workflow

Follow this path the first time you use the app:

1. **Brainstorm** — Add an idea (or generate suggestions), then **Score with AI**.
2. **Promote to Project** — Creates your project plus starter tasks and milestones.
3. **Build Tracker** — Work the board (To Do → In Progress → Done); check off milestones.
4. **Lead Finder** — Search your niche, draft a reply, **Copy & mark contacted**, paste into the community thread.
5. **Growth Engine** — Save your **Brand voice**, generate this week’s **Growth Coach** plan, optionally activate a **Launch Playbook**.
6. **Revenue** — Load sample data to explore the screens, or use subscribe options if plans are available.
7. **Settings** — Note your AI / leads / projects usage so you know your limits.

When a build is ready to market, use **Launch Mode** from Build Tracker to jump into Growth with playbooks and coach tuned for that release.

## 5. Command Center (Overview)

**How to open:** Sidebar → **Overview**  
**Page title:** Command Center

### What you’ll see

- **Summary cards** — scored ideas, active tasks, milestones progress, pipeline leads, monthly revenue.
- **Project Journeys** — each project’s status, progress, and recent activity. Click **Open** to jump to Build Tracker.
- **Milestone Progress** — overall and by project; **Manage** opens Build Tracker.
- **Recent Ideas** — latest ideas and scores; **View all** opens Brainstorm.

### When it’s empty

If you haven’t promoted anything yet, you’ll see prompts to add ideas in Brainstorm or promote a lead. That’s normal — Overview fills in as you work.

### Tips

Use Overview as your morning check-in: what’s active, what’s overdue, and which project needs attention.

## 6. Brainstorm & Ideas

**How to open:** Sidebar → **Brainstorm & Ideas**  
**Page title:** Brainstorm & Idea Scorer

Two tabs: **Idea Scorer** and **Canvas**.

### Idea Scorer (simple list)

**Add ideas**

1. Optionally use **AI Idea Assistant**: enter a niche → **Generate** → select suggestions → **Add selected**.
2. Or fill **New Idea** (title and description) → **Add Idea**.
3. Optional: with a draft title filled, use **Enhance current draft with AI**.

**Score an idea**

1. Find the idea card.
2. Click **Score with AI** (or **Re-score** later).
3. Review the score label (for example Weak / Moderate / Strong / Exceptional) plus strengths, weaknesses, and recommendations.

**Promote, archive, or delete**

- **Promote to Project** — turns the idea into a project and adds starter tasks & milestones. You’ll get a confirmation message with the project name.
- **Archive** — hides the idea from your main list.
- **Delete** — removes it.

Promote is hidden once an idea is already promoted.

### Canvas (visual brainstorming)

Use Canvas when you want a session with branching ideas and an AI co-pilot.

1. Create a **Session** on the left (or pick an existing one).
2. Add a root idea, or type a prompt and **Generate**.
3. On each node you can explode, enhance, validate, analyze, develop, archive, delete, or branch.
4. Use the **AI Co-pilot** on the right for prompts like “What’s the strongest idea?”
5. When ready, **Promote to Project** from a node.

### Tips

- You don’t need a project before scoring ideas.
- Promote from either Idea Scorer or Canvas — both create a project you can open in Build Tracker.
- Heavy AI use counts against your hourly AI limit (see Settings).

## 7. Build Tracker

**How to open:** Sidebar → **Build Tracker**

Manage projects, tasks, milestones, builds, repo links, and project profile details.

### If you have no projects yet

You’ll see a message to promote a scored idea **or** click **New project** to create one manually. When creating manually you can check **Generate AI starter tasks & milestones**.

### Select and manage a project

- Click a project pill at the top.
- Use edit (pencil) or delete (trash) as needed.
- Project status can include planning, building, launched, or archived.
- Badges may show linked ideas or leads.

### Tabs

#### Tasks & milestones

- **Launch milestones** — checklist you can mark complete.
- **Kanban board** — columns **To Do**, **In Progress**, **Done**. Drag cards between columns.
- **Add a task** — title, priority (Urgent / High / Medium / Low), then **Add**.
- **Generate with AI** — creates suggested tasks for the project.
- Filter by priority if the board gets busy.
- Click a task to open details (description, labels, checklist, and more).

#### Builds & releases

- Track builds through a status pipeline.
- When a build is ready to market, a banner may offer **Enter Launch Mode**.
- Create or manage release notes and related build info when available.
- Empty state: “No builds yet.”

#### Repository & CI

- Link or view repository monitoring for **this** project (related to the Repository area of the app).

#### Project profile

- Version, production URL, hosting details.
- Optional Vercel connection fields.
- Environment variables, tech stack, tools, and notes for your own reference.

### Launch Mode

**What it is:** A bridge from “we shipped” to “we’re marketing.”

**How to access**

1. Open Build Tracker and select the project.
2. When a build is in a launch-ready state, click **Launch Mode** or **Enter Launch Mode**.
3. You’re taken to **Growth Engine** for that project with coach and playbooks prepared for the release.

If you don’t see Launch Mode yet, keep advancing builds until one is ready to market.

## 8. Lead Finder

**How to open:** Sidebar → **Lead Finder**

Find real conversations (for example on Reddit and Hacker News), save them as leads, draft replies, and track outreach.

### Search for leads

1. Enter a niche (example: *SaaS for real estate agents*).
2. Click **Find posts** (while working you’ll see **Mining posts…**).
3. Review the cards that appear — live posts show author, community, post text, suggested **Approach**, relevance, and engagement.

### Add a lead manually

Click **Add manually**, fill Title/Name (required), optional description, source, and URL → **Save Lead**.

### Filter

Use **All leads**, **Unassigned**, or a specific project.

### Work a lead

On a lead card you can:

| Action | What it does |
|--------|----------------|
| **Open thread** / open post | Opens the original conversation |
| **Draft reply** / **Regenerate reply** | AI writes a paste-ready reply (uses brand voice when a project is selected) |
| **Copy & mark contacted** | Copies the reply and logs that you reached out |
| **Mark Qualified / Contacted / Rejected** | Updates status manually |
| **Promote to project** (rocket) | Creates a project from the lead (if not already linked) |
| **Delete** | Removes the lead |

Statuses you’ll see include **new**, **qualified**, **contacted**, **rejected**, and related labels like intent badges (for example Buying intent or Pain signal).

### Suggested outreach flow

1. Find posts → read the thread.
2. **Draft reply** → edit if needed.
3. **Copy & mark contacted**.
4. Paste into the community (follow that community’s rules — be helpful, not spammy).
5. Optionally promote promising leads into a project.

### Tips

- Select a project filter before drafting if you want replies aligned with that project’s brand voice (set voice in Growth Engine).
- Lead counts may be limited by your plan — see Settings.
- If few “live posts” appear, try a clearer niche or try again later (community sources can be temporarily unavailable).

## 9. Growth Engine

**How to open:** Sidebar → **Growth Engine**

Built for solopreneurs who are **not** full-time marketers: weekly coaching, content planning, launch checklists, campaigns, and SEO keywords.

### Before you start

You need at least one project. If you see “Create a project first…”, promote an idea from Brainstorm (or create a project in Build Tracker).

Select the project with the pills at the top.

### Launch Mode banner

If you arrived from Build Tracker Launch Mode, you’ll see a **Launch Mode** banner (coach + playbooks tuned for that version). Use **Open playbooks** or work the Coach tab. You can dismiss/continue with the project selected.

### Tabs

#### Growth Coach

1. Click **Create this week's plan**, **Generate plan**, or **Regenerate**.
2. Review the focused actions (channel + effort level).
3. Check actions off as you complete them.

**Brand voice** (on the same tab):

- Fill **Tone**, **Avoid**, and **Audience**.
- Click **Save voice**.
- This voice is used for rewrites, content fan-out, coach context, and lead reply drafts.

#### Content Calendar

1. **Quick add draft** (type and press Enter), or use **AI ideas**, or **Plan 2 weeks**.
2. Move through the month with Prev / Today / Next.
3. Click an item to edit status (draft / scheduled / published), channel, body.
4. From the detail view you can rewrite with brand voice, create channel fan-out pieces, A/B variants, hashtags, or delete.

#### Launch Playbooks

Interactive checklists with AI copy packs (not just external bookmarks).

1. Expand a playbook (examples include major launch channels such as Product Hunt or Indie Hackers).
2. **Activate + generate copy** when you want checklist + suggested copy.
3. Check off steps; use **copy** on copy packs; **Open site** when you need the destination.

#### Campaigns

1. Enter campaign name, choose a channel, add notes → **Add**.
2. Update status: draft, active, paused, or completed.
3. Delete campaigns you no longer need.

#### SEO

1. Add keywords manually, or click **AI Suggest**.
2. Review volume / difficulty style metrics on the list.
3. Delete keywords you don’t need.

Treat SEO numbers as planning aids, not guaranteed search traffic.

## 10. Revenue & Billing

**How to open:** Sidebar → **Revenue & Billing**  
**Page title:** Revenue & Analytics

### What you can do

- View **Monthly Recurring Revenue**, total revenue, active subscriptions, and average revenue per user.
- Browse **Subscriptions** and **Transactions** tables.
- See **Marketing Campaigns** related to spend/tracking when present.
- If plans are available, use **Subscribe to …** to go through checkout.
- If there’s no data yet, click **Load sample data** to explore the screens with example numbers.

### Tips

- Sample data is for learning the layout — it is not your real Stripe balance.
- When live billing is connected for your account, real subscriptions and transactions appear in these tables.

## 11. Repository & VCS

**How to open:** Sidebar → **Repository & VCS**  
**Page title:** Repository & CI Monitoring

Connect a GitHub repository to a project and watch branch health, pull requests, and builds.

### Steps

1. Select a project (promote an idea first if you have none).
2. Enter the **GitHub URL**.
3. Optionally provide a **GitHub token** with access to that repo → **Save connection**.
4. When connected, review stats (stars, forks, issues, language) when available.
5. Use **Repo monitoring** tools: branch health, webhook endpoint (copy for setup), **Sync from GitHub**, and delivery history.

### Tips

- Live stats and webhooks may require a valid token and webhook setup. If you only see “Repository linked” without live stats, add a token in the form or ask whoever manages your hosting to finish GitHub setup.
- Branch routing guidance in the UI (for example main → Staging) helps you understand where builds are expected to land.

## 12. Settings, privacy & limits

**How to open:** Sidebar → **Settings**

### Production readiness (health)

A status badge shows whether core services look healthy. You’ll see checks for things like database, sign-in, payments, AI, and webhooks. Use **refresh** if you just changed configuration.

Most solo users mainly care about the **Plan usage** section below these checks.

### Plan usage

Watch:

- **AI calls** this hour (used / remaining / limit, and when it resets)
- **Leads** used vs limit
- **Projects** used vs limit

If Score, Find posts, Generate plan, or similar actions fail, check this panel first.

### Privacy & your data

- **Export my data** — downloads a JSON file of your projects, ideas, leads, and related information (for your records / GDPR-style access).
- **Delete account** — permanently removes your account and data after confirmation. This cannot be undone. You’ll return to the home page.

Links to the full **Privacy Policy** and **Terms of Service** are available here and in the sidebar footer.

## 13. Tips & troubleshooting

| Situation | What to try |
|-----------|-------------|
| Can’t open dashboard | Sign in again from the home page (**Sign in** / **Get started**). |
| “Create a project first” | Go to Brainstorm → score an idea → **Promote to Project**, or use **New project** in Build Tracker. |
| AI buttons fail or feel blocked | Open **Settings** → check AI calls remaining; wait for the hour to reset or reduce AI actions. |
| Lead search returns few live posts | Try a more specific niche; try again later; add important leads **manually**. |
| No Launch Mode button | Finish a build until it’s in a ready-to-market state; then use **Enter Launch Mode**. |
| Draft reply feels generic | In Growth Engine → Growth Coach, save **Brand voice**, select that project in Lead Finder, then draft again. |
| Revenue looks empty | Use **Load sample data** to explore, or complete a subscribe/checkout flow when plans are shown. |
| GitHub shows linked but no stats | Add a personal access token in Repository for that project; confirm webhook setup if you need automatic builds. |
| Want a copy of your data | Settings → **Export my data**. |
| Leaving the product | Settings → **Delete account** (permanent). |

### Good habits

- Score before you build — use Idea Scorer so you don’t commit weeks to a weak idea.
- One project focus per week in Growth Coach — check off the five actions.
- Always **Copy & mark contacted** so your pipeline stays honest.
- Use Launch Mode at ship time so playbooks and coach start together.

| **Project** | The hub for tasks, growth, repo, and related activity |
| **Milestone** | A larger launch checkpoint on the way to shipping |
| **Lead** | A person or post worth following up with |

| **Growth Coach** | Weekly (or launch-week) action plan |

| **MRR** | Monthly Recurring Revenue from subscriptions |
| **Canvas** | Visual brainstorming sessions with branching ideas |
